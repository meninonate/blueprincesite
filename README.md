Qual é a função do HTML na página desenvolvida?

- Apresentar o jogo Blue Prince, explicando desde o seu conceito até a sua criação.

Onde você utilizou CSS e quais alterações ele realizou?

- Utilizei o CSS em todos os elementos, desde o texto (h1, h2, p) até demais elementos que compõem a página (background, img, buttom)

Onde você utilizou JavaScript e o que acontece quando ele é executado?

- O Javascript foi usado apenas na interação do botão. Ao clicar no botão, você é redirecionado a uma nova página. A página de compra do jogo.

Qual é a principal diferença entre CSS e JavaScript?

- O CSS é responsável pela aparência da página, alterando o design dos elementos. Já o Javascript é responsável pela funcionalidade e a usabilidade dos itens. Um exemplo é o próprio botão que eu mencionei mais cedo, que, quando clicado, ativa um comando para que tal coisa ocorra, nesse caso: redirecionar o usuário a uma nova página.
